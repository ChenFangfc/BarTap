BarTap 安装说明 / Install
==========================

【中文】
1. 把 BarTap.app 拖到「应用程序」(Applications) 文件夹。
2. 第一次打开：双击 BarTap。如果 macOS 提示"无法验证开发者"：
   打开「系统设置 › 隐私与安全性」，在页面底部找到 BarTap，点「仍要打开」。
   （BarTap 没有使用付费的 Apple 开发者证书签名，所以需要这一步，只需一次。）
   也可以在终端执行：  xattr -dr com.apple.quarantine /Applications/BarTap.app
3. 菜单栏右侧会出现 BarTap 开关（BarTap 标志）。在「设置 › 布局」里选择隐藏哪些图标，
   或自己按住 ⌘ 把图标拖到 │ 分隔线左边；点按开关（或 ⌃⌥⌘B）显示/隐藏。
4. 可选：在「系统设置 › 隐私与安全性 › 辅助功能」中允许 BarTap，即可使用图标架
   （点开关弹出隐藏图标的下拉栏，刘海屏很有用）、图标搜索（⌃⌥⌘F）和「设置 › 布局」
   （拖动图标排好显示/隐藏和顺序，点「应用」）；再允许「录屏」，这些地方会显示真实图标。
   隐藏功能本身不需要任何权限，升级后授权也会保留。
5. 如果你在用 Bartender / Ice / Hidden Bar，请先退出它们，避免两个工具抢同一批图标。
6. 系统监控（CPU、GPU、内存、磁盘、网络、传感器、电池、时间、音量、蓝牙、三合一状态图标）和 AI 用量
   （Claude Code、Codex 等的 token、费用和套餐额度）都在「设置 › 系统监控」里打开。AI 用量只读本机日志，
   不要密钥，不用登录。
7. 下载视频：BarTap 菜单 › 下载视频…（基于 yt-dlp；没装的话，可在那里从它的 GitHub 官方发布页获取）。
   请只下载你有权下载的视频。

隐藏图标时 BarTap 不发送任何模拟输入、不拦截点击、不瞬移指针（构建时自动检查）。
只有你在「设置 › 布局」点「应用」时，它才会像你一样逐个 ⌘ 拖动图标；你一碰鼠标或键盘就立刻停止。
退出 BarTap 后，所有图标会立刻恢复原样。

【English】
1. Drag BarTap.app into Applications.
2. First launch: if macOS says the developer cannot be verified, open
   System Settings › Privacy & Security and click "Open Anyway" next to BarTap
   (BarTap is self-signed, not notarized). Or run:
   xattr -dr com.apple.quarantine /Applications/BarTap.app
3. Choose what to hide in Settings › Layout, or ⌘-drag menu bar icons left of the
   │ divider yourself; click the toggle (the BarTap mark) or press ⌃⌥⌘B to
   show/hide them.
4. Optional: allow BarTap under Privacy & Security › Accessibility to enable the
   shelf, a dropdown of hidden icons (handy beside the notch), icon search (⌃⌥⌘F)
   and Settings › Layout (drag icons into Shown/Hidden and order, then Apply); allow Screen
   Recording too for real icons there. Hiding itself needs no permission, and
   grants survive updates.
5. Quit other menu bar managers (Bartender, Ice, Hidden Bar) first.
6. Turn on system stats (CPU, GPU, memory, disk, network, sensors, battery, time,
   volume, Bluetooth, a 3-in-1 status icon) and AI usage (tokens, cost and plan
   limits of Claude Code, Codex and others) in Settings › Stats. AI usage only reads
   local logs: no keys, no sign-in.
7. Video downloads: BarTap menu › Download Video… (uses yt-dlp; if it isn't installed,
   BarTap can fetch its official release from GitHub there). Download only videos you
   have the right to.

Hiding never posts synthetic input, never blocks clicks and never warps the pointer
(verified at build time). Icons move only when you click Apply in Settings › Layout:
BarTap then ⌘-drags them one by one, as you would, and stops as soon as you touch the
mouse or keyboard. Quitting BarTap instantly restores every icon.
