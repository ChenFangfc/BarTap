BarTap 安装说明 / Install
==========================

【中文】
1. 把 BarTap.app 拖到「应用程序」(Applications) 文件夹。
2. 第一次打开：双击 BarTap。如果 macOS 提示"无法验证开发者"：
   打开「系统设置 › 隐私与安全性」，在页面底部找到 BarTap，点「仍要打开」。
   （BarTap 没有使用付费的 Apple 开发者证书签名，所以需要这一步，只需一次。）
   也可以在终端执行：  xattr -dr com.apple.quarantine /Applications/BarTap.app
3. 菜单栏右侧会出现 BarTap 开关（BarTap 标志）。按住 ⌘ 把图标拖到 │ 分隔线左边即可隐藏；
   点按开关（或 ⌃⌥⌘B）显示/隐藏。
4. 可选：在「系统设置 › 隐私与安全性 › 辅助功能」中允许 BarTap，
   即可使用图标搜索（⌃⌥⌘F）和菜单栏下方的图标架。隐藏功能本身不需要任何权限。
5. 如果你在用 Bartender / Ice / Hidden Bar，请先退出它们，避免两个工具抢同一批图标。
6. 系统监控（CPU、GPU、内存、磁盘、网络、传感器、电池、时间）在「设置 › 系统监控」里打开。

BarTap 从不发送模拟鼠标/键盘事件，从不移动指针，也不拦截点击（构建时自动检查）。
退出 BarTap 后，所有图标会立刻恢复原样。

【English】
1. Drag BarTap.app into Applications.
2. First launch: if macOS says the developer cannot be verified, open
   System Settings › Privacy & Security and click "Open Anyway" next to BarTap
   (BarTap is ad-hoc signed, not notarized). Or run:
   xattr -dr com.apple.quarantine /Applications/BarTap.app
3. ⌘-drag menu bar icons left of the │ divider to hide them; click the toggle
   (the BarTap mark) or press ⌃⌥⌘B to show/hide them.
4. Optional: allow BarTap under Privacy & Security › Accessibility to enable icon
   search (⌃⌥⌘F) and the shelf. Hiding itself needs no permission.
5. Quit other menu bar managers (Bartender, Ice, Hidden Bar) first.
6. Turn on system stats (CPU, GPU, memory, disk, network, sensors, battery, time)
   in Settings › Stats.

BarTap never posts synthetic mouse/keyboard events, never moves the pointer and never
blocks clicks (verified at build time). Quitting BarTap instantly restores every icon.
