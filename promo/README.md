# Promo film

The film and the README media are rendered from code. There is no screen recording and no personal data.

```bash
promo/build.sh       # English: docs/media/bartap-film-en.mp4, bartap-preview.webp, screenshots
promo/build.sh zh    # Chinese: docs/media/bartap-film-zh.mp4, bartap-preview-zh.webp
```

| File | Role |
| --- | --- |
| `film.swift` | The compositor. Each frame is a pure function of time, drawn with AppKit and piped as raw RGBA into ffmpeg. `film <repo> 12.6` writes one still, and `film <repo> cues` lists the sound cues. |
| `music.py` | The soundtrack, synthesised with numpy and scipy at 120 BPM (the film's `beat`). Every on-screen event sits on its eighth-note grid. |
| `shots.swift` | Composes the README screenshots. |
| `assets/` | Generated by `BarTap --export-promo-assets` (BarTap's real menu bar items and dropdowns) and `BarTap --render-downloads` (its download panel), all from sample data. `assets/film/` holds the film's details in English and Chinese: the Power panel without its dots plus `power_<lang>.json` (where its flows run, so the film moves the dots the way the app does), the same panel pointing at the CPU's flow, and the montage's panels. Delete the folder to pick up app changes. |

The film runs 49 s at 120 BPM: the crowded bar (0 s), the twitching (2.5), the mark (5), hiding (8), stats with hover details (12), AI usage (16), the lid (20), downloads (24), Power: where every watt goes, then the whole panel named part by part (28), every item's details side by side (36), the feature cards (40), the numbers and the end card (44).

Needs the Command Line Tools, python3 with numpy and scipy, ffmpeg, and libwebp (`img2webp`, `cwebp`).
