# Promo film

The film and the README media are rendered from code. There is no screen recording and no personal data.

```bash
promo/build.sh       # English: docs/media/bartap-film-en.mp4, bartap-preview.webp, screenshots
promo/build.sh zh    # Chinese: docs/media/bartap-film-zh.mp4, bartap-preview-zh.webp
```

| File | Role |
| --- | --- |
| `film.swift` | The compositor. Each frame is a pure function of time, drawn with AppKit and piped as raw RGBA into ffmpeg. `film <repo> 12.6` writes one still, and `film <repo> cues` lists the sound cues. |
| `music.py` | The soundtrack, synthesised with numpy and scipy at 100 BPM. Every on-screen event sits on its eighth-note grid. |
| `shots.swift` | Composes the README screenshots. |
| `assets/` | Generated by `BarTap --export-promo-assets`: BarTap's real menu bar items and dropdowns, drawn from sample data. |

Needs the Command Line Tools, python3 with numpy and scipy, ffmpeg, and libwebp (`img2webp`, `cwebp`).
